# Sistema de préstamos

Consulta `../LEEME_PRIMERO.md` antes de ejecutar esta versión. Requiere la migración de cartera por agencia y pagos, que todavía no está aplicada al proyecto real.

Desde esta carpeta: `npm install`, luego `npm run dev`. Para producción: `npm run build` y `npm start`.

Pruebas SQL aisladas: desde tests ejecuta `npm install` y `npm test`. No se conectan al proyecto real.
